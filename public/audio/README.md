# ボイスショップ 音声ファイル配置場所

このディレクトリにボイスショップ用の音声ファイルを配置してください。

## ファイル一覧

| ファイル名 | 説明 |
|------------|------|
| `voice_b.wav` | ボイスB「もっとがんばるのだ！（激熱応援）」 |
| `voice_c.wav` | ボイスC「だらけちゃダメなのだ！（ツンデレ怒り）」 |

## 仕様

- フォーマット: WAV
- 長さ: 3〜10秒程度
- サンプルレート: 44100Hz以上推奨

ファイルを配置したら、`/audio/voice_b.wav` などのパスで自動的にアクセスできるようになります。
